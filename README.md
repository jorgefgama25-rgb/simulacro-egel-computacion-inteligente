# Simulacro EGEL — Computación Inteligente

Simulacro académico interactivo de 140 reactivos, organizado en cuatro áreas:

- Análisis y diseño de sistemas
- Desarrollo e implementación de software
- Gestión de bases de datos y redes
- Cómputo inteligente y tecnologías emergentes

El sitio funciona como una sola página, guarda el progreso localmente en el navegador y muestra retroalimentación inmediata.

> Este es un recurso académico no oficial creado con fines de estudio. No está afiliado ni avalado por CENEVAL.
